# Software Subgroup

The Software subgroup develops all code systems that control the robot, from autonomous operation during the first 15 seconds of a match to driver-controlled systems during competition. We are the brains behind the robot.

## What We Do

### Robot Programming
- Autonomous code for the first 15 seconds of each match
- Teleop (driver-controlled) systems and controls
- Subsystem programming (drivetrain, shooter, intake, etc.)
- Motor and servo control
- Sensor integration and feedback systems

### Vision & Targeting
- Camera calibration and setup
- Computer vision algorithms
- Target detection and tracking
- Aiming and shooting automation
- Real-time image processing

### Control Systems
- PID control loops for precise movement
- Feedback and sensor integration
- Motion profiling and trajectory planning
- Emergency stop and safety systems

### Dashboard & Diagnostics
- Driver dashboard for competition
- Debugging tools for development
- Telemetry data collection
- Performance monitoring and logging

### Testing & Optimization
- Simulation and bench testing
- Competition data analysis
- Code optimization for performance
- Continuous improvement

## Skills You'll Develop

- **Programming Languages** – Java (primary FRC language), C++, Python
- **Real-Time Systems** – Understanding timing and responsiveness
- **Robotics Framework** – WPILib and FRC-specific libraries
- **Version Control** – Git and GitHub
- **Testing & Debugging** – Problem-solving and diagnostics
- **Collaboration** – Working with hardware teams
- **Mathematics** – Geometry, trigonometry, kinematics
- **Problem-Solving** – Algorithmic thinking

## Responsibilities

### During Build Season
- Design and implement autonomous routines
- Develop teleop control systems
- Integrate with electrical and mechanical subsystems
- Write clean, well-documented code
- Test on practice robot
- Optimize performance based on feedback
- Mentor newer programmers

### During Competition Season
- Deploy and debug code at events
- Analyze match data and performance
- Make real-time adjustments
- Support pit operations with diagnostics

### Off-Season
- Study new programming techniques
- Contribute to open-source FRC projects
- Mentor new team members
- Plan for next season

## Tools & Technologies

### Programming Environment
- **WPILib** – Official FRC programming library
- **VS Code** – Code editor with FRC extensions
- **Java** – Primary programming language
- **Git/GitHub** – Version control

### Simulation & Testing
- **WPILib Simulation** – Robot code simulation
- **Shuffleboard** – Dashboard and diagnostics

- **RoboRIO** – Robot controller

## Join Software

### No Programming Experience Required!

We welcome students with all backgrounds:
- Never coded before? We'll teach you Java
- Beginner programmer? Great, you'll advance fast
- Experienced coder? Perfect for advanced projects

### How to Get Started

1. **Learn Java basics** – Online tutorials or team training
2. **Attend a team meeting** – See robots in action
3. **Set up development environment** – We'll help you
4. **Start with simple tasks** – Subsystem programming
5. **Advance to complex systems** – Autonomous and integration
